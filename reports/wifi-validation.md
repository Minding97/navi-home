# Wi-Fi 연결 관리 — 수신 앱 0.4

## 구현

- 홈과 미러링 화면에서 `Wi-Fi 연결 관리`로 진입한다.
- Android Wi-Fi 설정 또는 제조사 `휴대폰 연결` 메뉴를 연다.
- 현재 연결 또는 기기에 저장된 목록에서 대상을 기억한다. 앱에는 프로필 식별 정보만 저장하고 비밀번호를 보관하지 않는다.
- Android 5(API 21~22)에서 완전 부팅 알림을 받으면 선택한 대상을 최대 60초 동안 찾는다. Wi-Fi가 꺼져 있으면 켜기를 요청한다. 켜기 및 연결 요청 간격은 각각 최소 20초다.
- 연결 요청 수락과 실제 연결 완료를 구분한다. IP가 할당된 Wi-Fi 연결과 저장된 프로필의 네트워크 ID가 일치해야 완료한다.
- 매번 저장 정보를 다시 조회하므로 재부팅 후 바뀐 ID나 같은 이름의 다른 보안 프로필을 대신 선택하지 않는다. 중복 프로필은 설정에서 정리하도록 안내한다.
- 부팅 시 다른 Wi-Fi가 이미 연결되어 있으면 유지한다. 수동 `다시 연결`은 기억한 대상으로 변경을 요청한다.
- Android 5의 대상 선택 호출은 다른 프로필을 일시 비활성화할 수 있다. 호출 직후 기존에 활성화되어 있던 프로필만 재활성화하며 ID와 식별 정보가 여전히 같은지 확인한다. 복구 요청이 거부되면 실패를 표시한다.
- 타임아웃·권한 거부·사용자의 중지·연결 후 Wi-Fi 끄기를 처리한다. 서비스는 자동 재시작하지 않으며 화면을 띄우지 않는다.
- Android 6 이상은 직접 제어를 비활성화하고 설정 바로가기를 제공한다. 구형 앱을 최신 Android에 설치한 시험 결과를 iQ 3의 Wi-Fi 제어 성공으로 해석하지 않는다.
- 기존 패키지 `local.navi.diagnostic`, 서명, 부팅 홈 진입, 카메라 앞에서 일시중지하는 미러링 동작을 유지했다.

## 검증 자료

- `wifi-policy-tests.txt`: 가짜 네트워크 포트를 사용한 순수 Java 정책 시험 20개. 지연된 동글 시작, 타임아웃, ID 변경·재사용, 다른 네트워크, 권한 거부, 취소를 포함한다.
- `wifi-emulator-checks.json`: 임시 API 36 / 800×480 에뮬레이터의 업데이트와 UI 이동 검사 13개 통과. Wi-Fi 연결 자체를 시험하는 자료가 아니다.
- `wifi-management-emulator.png`: API 36에서 직접 제어가 비활성화된 관리 화면.
- `wifi-build.txt`: 빌드, APK 서명 검증, 패키지·버전·권한 정보.
- `wifi-api-review.txt`: 호출 API 정적 검사. 추가한 Wi-Fi 코드는 API 21 범위다. 기존 MainActivity의 API 23 권한 결과 콜백은 해당 플랫폼에서만 전달되는 콜백이다.
- 기존 전송 프로토콜 시험 22개도 통과했다. 0.4에서 장시간 영상 재생 시험을 새로 수행하지 않았다. 이전 버전의 영상 시험 범위는 `mirroring-validation.md`를 따른다.

## 실제 기기에서 남은 확인

1. Wi-Fi 동글 인식과 표준 WifiManager 제어 허용 여부.
2. 제조사 연결 설정의 실제 진입 위치.
3. 처음 연결한 Z Flip7 핫스팟 기억, 완전 재부팅 자동 연결, 늦게 켠 핫스팟 수동 연결.
4. 핫스팟 부재 시 60초 종료, 설정에서 Wi-Fi 끄기, 자동 연결 해제.
5. 업데이트 후 앱 자동 실행, 파인 홈 복귀, R/D 카메라와 미러링 공존.

빠른 재시동이나 절전 복귀에서 BOOT_COMPLETED가 오지 않으면 앱의 부팅 연결 시도도 시작되지 않는다. 이 경우 기기의 기본 자동 연결 또는 수동 버튼을 사용한다. 휴대폰 MediaProjection 승인은 자동으로 처리하지 않는다.

## 근거

- 카드의 `Setting.apk` 정적 분석: `com.finedigital.setting.ActivitySetting`은 런처로 공개되어 있으며, `ActivitySetting$1.run()`이 `categoryName`을 읽는다. 동일 앱의 다른 경로에서도 `휴대폰 연결` 값을 전달한다. 실제 화면 진입은 미검증이다. 분석 위치는 `analysis/dex/Setting-dump.txt`의 126775, 126850, 159862행 부근이다.
- [Android WifiManager 공식 문서](https://developer.android.com/reference/android/net/wifi/WifiManager): 저장 프로필 조회, 연결 요청의 비동기 동작, 최신 플랫폼의 제어 제한. 대상 장치의 펌웨어가 해당 API를 허용한다는 보장은 아니다.

## 배포

최종 APK와 WIFI-TEST-0.4-KO.txt를 SD카드 NaviTest에 추가하고 SHA-256 일치를 확인했다. 기존 제조사 파일은 변경하지 않았다. 이번 배포 후 정상 추출에 성공했다. 기기에서의 설치·실행은 사용자가 진행해야 한다. 배포 기록은 `car-test-deployment-0.4.json`에 있다.

# iQ 3 Wi-Fi 확인과 오프라인 전환 — 2026-09-17

## 사용자 실물 확인

- 사용자가 GPS 수신을 확인했다. 새 0.6 앱의 속도·거리 정확도 검증을 뜻하지 않는다.
- Wi-Fi가 지원되지 않는 것처럼 보인다고 보고했다. 실제 USB 장착 상태, 동글 모델, 기능 선언, 오류 화면은 아직 없다.
- 과거 0.2 부팅 자동 실행 및 R/D 카메라 전환 확인은 유지한다. 0.6 공존은 별도 시험 대상이다.

## 공식 자료에서 확인한 사실

iQ 3 정확한 모델의 공식 사용설명서(로컬 원본 /tmp/Manual_User_iQ3.pdf)를 PDFKit으로 렌더링하여 읽었다.
- 인쇄 21쪽 ‘별매품’: ‘리얼타임3D 전용 WiFi 동글’과 ‘블루투스 동글’을 각각 안내한다.
- 22쪽: 측면 표준 USB 단자.
- 42쪽 ‘휴대폰 연결’: 앱을 이용한 Wi-Fi/블루투스 연결 외에 핫스팟 비밀번호를 입력하는 수동 연결을 안내한다.
- 따라서 Wi-Fi 연결 기능이 전혀 없는 모델로 단정하면 안 된다. 별도 호환 동글을 통한 연결 경로를 확인해야 한다. 현재 동글 부재/미인식 여부는 미확인이다.
- 일반 USB 무선랜, RTL8188 계열의 모든 제품, 파인뷰 블랙박스용 BT+WiFi 동글을 호환 제품으로 확정하지 않는다. 칩셋뿐 아니라 펌웨어 드라이버/USB 식별자/포트 구성을 검증해야 한다.

## 이번 구현 범위

네트워크 확보를 전제하지 않고 GPS, 시계, 앱 실행, 로컬 설정을 이용하는 0.6 홈을 구현한다. 미러링/Android Auto는 기존 시험 화면으로 보존한다. OBD는 사용자의 요청대로 다음 단계에 둔다.

시각 기준은 차콜 #101718, 카드 #1B2527, 청록 #68DDC1, 본문 #EEF4F2, 보조 #A7B8B4. 800x480 화면 바깥 여백20px/위아래16px, 타일 간격12px, 주요 버튼56~64px, 속도92px, 시계68px. 플랫폼 기본 서체를 사용하며 주요 화면은 스크롤 없이 표시한다. 실제 앱 캡처가 시안이다.

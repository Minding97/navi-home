# 미러링 검증 — 2026-09-16

## 구현 범위

수신 앱 0.3과 송신 앱 0.1을 구현했다. 두 앱의 화면 전송 경로는 아래와 같다.

휴대폰 화면 공유 → AVC 인코딩 → 로컬 암호화 TCP → 내비 AVC 디코딩 → 화면 표시.

실물 iQ 3 + Z Flip7 연결은 아직 검증하지 않았다. 사용자에게 확인된 기존 0.2의 자동 실행과 R/D 카메라 표시를 새 미러링 구현의 실물 성공으로 간주하지 않는다.

## 완료한 PC 검사

- 두 APK 빌드, ZIP CRC, APK 서명 검증 통과.
- 수신 0.3은 기존 0.2와 서명 인증서 일치. 수신 min API 21, 송신 min API 29.
- 프로토콜 검사 22개 통과: 정상 상호 인증, 잘못된 연결 코드, 암호화 왕복, 변조/재전송 거부, 잘린 패킷과 과도한 크기 거부, 코덱 설정 검증, 대기열 초과 뒤 keyframe 복구.
- SDK API 정적 검사: 수신 253개 / 송신 197개 플랫폼 호출 해석. 수신의 기존 위치 권한 콜백에서만 API 23의 super 호출이 있고 해당 콜백은 API 23 이상 시스템에서 호출된다. 신규 수신 코드에서 API 21 초과 호출은 발견되지 않았다. 정적 검사는 실제 Android 5 실행을 대체하지 않는다.

## 에뮬레이터 통합 검사

Android 16 / API 36 arm64 임시 가상 기기 두 대를 사용했다. 내비 화면은 800×480, 휴대폰은 720×1280에서 가로로 회전했다. 연결은 Mac의 ADB TCP 포워딩을 사용해 실제 휴대폰 핫스팟을 대체했다.

- 두 최종 APK 업데이트 설치 → 주소/코드 입력 → Android 화면 공유 동의 → 영상 수신 성공.
- 세로·가로 화면 전송과 원본 비율 유지 확인.
- 다른 앱 화면으로 이탈한 뒤 복귀하는 시험 5회 모두 약 15fps로 재개. 차량 기어/카메라 자체 시험은 아니다.
- 송신 프로세스 종료 3초 후 연결 끊김 안내와 영상 가림 확인.
- 602초 연속 전송에서 30초 간격 21개 표본 모두 15.0fps. 수신 앱 PSS는 32,459 → 39,621 KiB였다. 단일 시험으로 장기 메모리 누수 부재를 확정하지 않는다. 상세 값은 mirror-soak-test.json 및 mirror-memory-*.txt에 기록했다.
- 연속 재생에 사용한 수신 APK는 f2142345… 빌드다. 이후 화면 이탈 시 네트워크 read와 별도로 디코더를 해제하고 휴대폰 SCREEN_OFF 시 공유를 직접 종료하도록 보강했다. 최종 수신 빌드는 0c650d08…, 송신 빌드는 5f338179…이다. 최종 APK 설치·전송 시작, 화면 복귀 3회 모두 15fps, 화면 꺼짐 3초 후 영상 가림 및 MediaProjection=null을 확인했다. 상세 결과는 mirror-final-regression.json에 있다.

[수신 화면](mirror-receiver-emulator.png), [송신 화면](mirror-sender-emulator.png).

동시에 요청한 스크린샷의 시험 시계는 각각 969.384 / 969.532초로 약 148ms 차이다. 각 캡처 호출에 77ms / 123ms가 걸렸으므로 이 비교는 참고치이며 정밀한 전체 지연 판정이 아니다.

## 다음 실물 검사

- iQ 3 Wi-Fi 동글·핫스팟 연결 가능 여부.
- Z Flip7에서 실제 네이버지도 캡처 및 iQ 3 H.264 디코더 호환.
- 10분 실제 지도 재생, 10fps 이상, 외부 촬영으로 전체 지연 500ms 이하.
- R/D 카메라 우선 표시 및 앱 복귀, 휴대폰 회전·잠금·공유 취소·핫스팟 재연결.
- 기기 전원 재인가 후 자동 실행과 원래 홈 복귀.

이 결과를 받은 뒤 완성형 홈 화면과 GPS 주행 정보를 구현한다. 현재 APK에 미검증 차량 신호나 가짜 위치를 표시하지 않는다.

## 배포

최종 APK 두 개와 시험 안내를 SD카드에 복사하고 SHA-256 일치를 확인했다. 카드 정상 추출은 macOS loginwindow가 거부했으므로 ejected=false로 기록했다. 임시 에뮬레이터는 모두 종료하고 임시 가상 디스크를 제거했다.

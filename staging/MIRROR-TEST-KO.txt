Navi 미러링 1차 시험 — 수신 앱 0.3 / 휴대폰 송신 앱 0.1

목표
Z Flip7의 화면을 iQ 3에 표시할 수 있는지 확인합니다.
휴대폰에서 지도와 음성 안내를 실행하며, 내비에서는 화면만 표시합니다.
GPS 수신과 차량 이동은 이번 시험에 필요하지 않습니다.

준비 파일
- iQ 3용: NaviDiagnostic-0.3.apk (기존 Navi 진단 업데이트)
- Z Flip7용: NaviSender-0.1.apk (앱 이름: Navi 화면 전송)
- 두 APK는 서로 다른 기기에 설치합니다.

1. 내비 업데이트 및 Wi-Fi 확인
- 전원이 꺼진 내비에 SD카드를 넣고 켭니다.
- 숨겨진 앱 목록 > 파일 관리자 > 외부 SD > NaviTest > NaviDiagnostic-0.3.apk.
- 업데이트 설치 후 열기. 제목에 0.3이 보이는지 확인합니다.
- '휴대폰 지도 연결 · Wi-Fi / 영상 진단'을 누릅니다.
- Wi-Fi 서비스, IPv4 주소, H.264 디코더 지원 목록을 확인합니다.
  목록에 디코더가 나온다는 사실만으로 실물 영상 재생 성공을 확정하지 않습니다.

2. 네트워크 연결 — 아래 둘 중 하나
A. 차에서: Z Flip7 모바일 핫스팟을 켠 뒤 iQ 3를 그 핫스팟에 연결합니다.
   별도 공유기는 필요 없습니다. 내비가 연결 목록을 못 찾으면 2.4GHz 설정으로 먼저 시험합니다.
B. 집에서: 두 기기를 같은 Wi-Fi 공유기에 연결합니다.
   게스트 네트워크의 기기 간 통신 차단 기능은 연결을 방해할 수 있습니다.
- 내비의 Wi-Fi 설정 버튼이 열리지 않으면 파인 설정에서 연결합니다.
- Wi-Fi 서비스가 없거나 연결을 할 수 없으면, 진단 저장을 눌러 결과를 남깁니다.
  메뉴 이름이나 기능 선언만으로 동글 유무를 확정하지 않습니다. USB 포트·동글 실물도 확인해야 합니다.

3. 휴대폰 APK 설치
- NaviSender-0.1.apk를 Z Flip7으로 옮긴 뒤 '내 파일'에서 엽니다.
- 본인이 연 파일의 앱 이름이 'Navi 화면 전송'인지 확인하고 설치합니다.
- 해당 파일을 연 앱의 설치 권한 안내가 나오면 Android 안내에 따라 허용합니다.
- APK를 폰으로 옮기기 어렵다면 Mac에서 tools/serve_sender.py를 실행해 같은 Wi-Fi에서 다운로드할 수 있습니다.
  이 서버는 송신 APK와 체크섬만 제공하며 제한 시간이 지나면 종료됩니다.

4. 화면 연결
- 내비에서 '연결 대기'를 누릅니다.
- 내비 화면의 IPv4 주소와 16자리 연결 코드를 휴대폰 앱에 입력합니다.
  주소 칸에는 숫자와 점만 입력합니다. ':52741' 포트는 입력하지 않습니다.
  연결 코드의 하이픈과 공백은 있어도 없어도 됩니다.
- 휴대폰에서 '화면 공유 시작'을 누르고 Android 공유 안내를 승인합니다.
- 실제 지도 시험: '앱 하나'에서 네이버지도를 선택하거나 전체 화면 공유 후 네이버지도를 엽니다.
- 영상이 들어오면 내비가 영상 화면으로 전환합니다.
- 하단 '영상 / 연결 정보' 버튼으로 주소·진단 화면을 다시 볼 수 있습니다.
- 폰에서 목적지를 설정하고 가로 화면으로 두면 내비의 가로 화면을 더 넓게 사용할 수 있습니다.
  세로 화면과 회전 시에는 비율을 유지하며 여백이 생길 수 있습니다.

5. 정차 상태 시험 순서
- 10분 동안 실제 지도 화면이 유지되는지 확인합니다.
- 하단 fps는 내비 디코더의 출력 프레임 수입니다. 목표는 10fps 이상입니다.
- 전송 지연 시험: 휴대폰에서 전체 화면 공유를 시작하고 '지연 시험 화면'을 누릅니다.
  휴대폰과 내비의 숫자를 동시에 사진/영상으로 찍어 차이를 비교합니다. 목표는 500ms 이내입니다.
  진단의 '로컬 프레임 처리' 시간은 전체 전송 지연이 아닙니다.
- R → D 전환 시 후방·전방 카메라 화면이 정상 표시되는지 확인합니다.
- 카메라에서 우리 앱으로 돌아왔을 때 최신 영상으로 재개되는지 확인합니다.
  카메라를 닫거나 앱으로 돌아오는 동작은 제조사 동작을 따릅니다. 앱이 강제로 홈을 열지 않습니다.
- 폰 회전, 네이버지도 앱 공유 시 앱 전환, 핫스팟 끊김, 화면 공유 중지, 폰 잠금을 각각 시험합니다.
- 연결이 끊기면 내비는 약 2~3초 안에 이전 지도를 가리고 상태 안내를 표시해야 합니다.
- 폰 잠금/공유 종료 후에는 '화면 공유 시작'으로 다시 승인해야 합니다.
- 네트워크만 잠깐 끊긴 경우 승인된 공유 세션이 살아 있으면 재연결을 시도합니다.
- 마지막으로 기기 전원을 껐다 켜 자동 실행과 파인 홈 복귀를 확인합니다.

6. 결과 가져오기
- '영상 / 연결 정보' > '진단 저장'으로 외부 SD에 텍스트를 저장합니다.
- 저장 화면을 제공하지 않는 기기는 안내창으로 결과를 표시하므로 사진을 남깁니다.
- Wi-Fi 연결 여부, 실제 네이버지도 표시, fps, 지연, 10분 안정성, R/D 전환 결과를 각각 알려주세요.
- 진단 결과에는 코덱/빌드/로컬 IP와 상태 이력이 들어갑니다. 연결 코드·화면·지도 좌표는 저장하지 않습니다.

종료와 복구
- 휴대폰: '전송 중지' 또는 Android의 화면 공유 종료를 누릅니다.
- 내비: 연결 정보 화면에서 '닫기'를 누르면 서버가 종료됩니다.
- 자동 실행 원복은 기존 '자동 실행 해제' 버튼을 사용합니다.

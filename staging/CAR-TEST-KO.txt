Finedrive iQ 3 — 차에서 확인할 순서

준비 내용
- SD카드 최상위에 SHOW_APPLIST 빈 파일을 추가했습니다.
- NaviTest/NaviDiagnostic-0.1.apk는 자체 제작한 GPS/기기 정보 진단 앱입니다.
- 기존 제조사 파일과 지도 파일은 바꾸지 않았습니다.
- APK는 복사만 해 두었습니다. 아직 설치되지 않았습니다.

1. 내비게이션 전원이 꺼진 상태에서 SD카드를 꽂고 차량 전원에 연결합니다.
2. 부팅 후 30~60초 기다린 다음 제조사 홈 화면으로 이동합니다.
3. 화면 왼쪽 위에 앱 이름 또는 작은 앱 선택 드롭다운이 나타나는지 확인하고 눌러 봅니다.
   위치는 카드의 홈 앱 레이아웃 분석에 따른 예상이며 실물 확인 전입니다.
4. 목록을 연 화면을 사진으로 남겨 주세요. 전체 화면과 목록 내용이 보이면 좋습니다.

파일 관리자 또는 파일 탐색기가 목록에 있다면
5. 파일 관리자를 열고 외부 SD카드의 NaviTest 폴더로 이동합니다.
   Android 내부 경로 후보: /storage/sdcard1/NaviTest/
6. NaviDiagnostic-0.1.apk를 누릅니다.
7. 정상 Android 설치 화면이 나오면 앱 이름이 'Navi 진단'인지 확인하고 설치합니다.
   출처 불명 앱 차단 안내가 나오면 일단 해당 화면을 사진으로 남겨 주세요.
8. 설치 화면의 '열기'로 실행합니다. 기기 정보와 센서 목록 화면을 사진으로 남겨 주세요.
9. 실외 정차 상태에서 'GPS 시작'을 누르고 1~3분 정도 기다립니다.
   좌표/속도/정확도가 나오면 수신 성공입니다. 수신이 안 된다고 즉시 GPS 고장으로 판단하지 않습니다.
10. 'GPS 중지'와 '종료'가 작동하는지 확인합니다.

목록이나 설치 화면이 나오지 않으면
- 홈 화면 또는 나타난 안내를 사진으로 남겨 주세요.
- 파일 관리자가 없으면 이번에는 목록 내용만 확인하면 됩니다.
- 기기 초기화, 시스템 업데이트, 기존 앱 파일 교체는 이번 시험에 필요하지 않습니다.

후방카메라는 앱 실행 성공 후 정차 상태에서 별도로 확인합니다.
후진 신호 시 카메라가 표시되는지, 후진 해제 후 화면이 돌아오는지 확인합니다.

원래대로 돌리기
- 전원을 끄고 SD카드를 Mac에 다시 연결합니다.
- 이번에 추가한 SHOW_APPLIST 파일과 NaviTest 폴더만 제거하면 카드 변경은 원복됩니다.
- 실제로 설치한 'Navi 진단' 앱은 Android 앱 설정에서 따로 제거합니다.
- 별도로 바꾼 기기 설정은 해당 설정에서 따로 되돌려야 합니다.

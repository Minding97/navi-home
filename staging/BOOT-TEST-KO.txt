Finedrive iQ 3 — Navi 진단 0.2 부팅 시험

설치
1. 본체 전원이 꺼진 상태에서 SD카드를 넣고 전원을 켭니다.
2. 앞서 찾은 홈 화면 왼쪽 위 숨겨진 앱 목록에서 파일 관리자를 엽니다.
3. 외부 SD카드 > NaviTest > NaviDiagnostic-0.2.apk를 누릅니다.
4. 기존 'Navi 진단'을 업데이트 설치한 후 '열기'를 누릅니다.
5. 제목이 'Navi 진단 · 0.2'인지, '전원을 켠 뒤 앱 자동 실행'이 체크됐는지 확인합니다.
   GPS 시작은 누르지 않아도 됩니다. 설치 후 앱을 한 번 열어야 합니다.

부팅 시험
6. 정상적으로 기기 전원을 끈 뒤 다시 켭니다. 화면만 껐다 켜는 절전 복귀는 부팅 알림이 없을 수 있습니다.
7. Navi 진단이 자동으로 열리는지 확인합니다.
   홈 선택 창이 뜨면 'Navi 진단'을 선택하고 '항상'을 누르면 됩니다.
8. 자동으로 열리지 않거나 잠깐 열렸다 파인 홈으로 바뀌면:
   숨겨진 앱 목록에서 Navi 진단 수동 실행 → '기본 홈 설정' → Navi 진단 선택.
   다시 전원을 껐다 켜 시험합니다. 제조사가 기본 홈 설정을 막은 경우 안내창이 표시됩니다.
9. 계속 안 되면 앱의 '기본 홈' 및 '최근 부팅 알림' 문구와 화면 전환 순서를 알려주세요.
   제조사 시작 프로그램이 우선할 수 있어 이 APK만으로 자동 실행을 보장하지는 않습니다.

사용
- '파인 홈': 제조사 홈 화면으로 이동합니다. 자동 실행 설정은 유지됩니다.
- '파인 설정': 제조사 설정 앱을 엽니다.
- 'Android 설정': 일반 Android 설정 화면을 엽니다(기기가 제공할 때).
- GPS는 수동 시작이며, 앱 화면을 벗어나면 수신을 중지합니다.
- '종료'는 현재 화면을 닫습니다. 기본 홈 지정 상태에서는 시스템이 다시 홈을 표시할 수 있습니다.

자동 실행 해제 / 원복
- 앱의 '자동 실행 해제' → '해제'를 누릅니다.
  부팅 자동 실행을 끄고 우리 앱의 기본 홈 지정을 해제합니다.
  이어지는 홈 선택 설정에서 파인드라이브 홈을 선택하세요.
- 기본 홈 설정이 지원되지 않으면 '파인 홈'으로 이동하세요.
  다음에 시스템 홈 선택창이 나오면 파인드라이브 홈을 '항상'으로 선택합니다.
- 체크만 끄는 것은 부팅 알림 실행만 끕니다. 기본 홈 지정은 별도로 해제해야 합니다.
- 앱을 제거하려면 Android 설정의 앱 목록에서 'Navi 진단'을 삭제합니다.
  SD에서 APK를 지우는 것만으로 설치된 앱이나 기본 홈 설정이 삭제되지는 않습니다.

검증 범위
- 0.1과 같은 서명키로 빌드한 업데이트 APK이며 Android 5용 서명 검사를 통과했습니다.
- 0.1의 실제 설치·실행 및 숨겨진 파일 관리자 접근은 사용자 확인 완료.
- 0.2의 실제 자동 실행과 후방카메라 공존은 아직 검증 전입니다.
- 부팅 때 한 번 실행을 요청하며, 다른 화면을 감시하거나 반복해서 전면으로 나오지 않습니다.
- 제조사 앱·지도·펌웨어를 교체하지 않습니다.
- 정차 상태에서 후진 신호로 카메라가 표시되고 해제 후 정상 복귀하는지도 확인하세요.

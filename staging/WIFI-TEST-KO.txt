Navi 진단 0.4 — Wi-Fi 연결 관리

설치
1. SD카드 NaviTest/NaviDiagnostic-0.4.apk를 열고 기존 앱을 업데이트합니다.
2. 앱을 한 번 열어 주세요. 같은 패키지·서명으로 기존 부팅 자동 실행 설정을 유지합니다.
3. 휴대폰 송신 앱은 NaviSender-0.1.apk를 계속 사용합니다.

처음 연결
1. Z Flip7의 모바일 핫스팟을 켭니다. 별도 공유기는 필요 없습니다.
2. 내비 앱의 ‘Wi-Fi 연결 관리’ → ‘Wi-Fi 설정 열기’를 누릅니다.
   Android 설정이 열리지 않으면 ‘파인 연결 설정’을 사용합니다.
   이 버튼은 제조사 ‘휴대폰 연결’ 메뉴 진입을 요청합니다. 실제 진입 결과는 확인이 필요합니다.
3. 설정 화면에서 핫스팟 이름을 선택하고 비밀번호를 입력해 연결합니다.
4. 우리 앱으로 돌아와 현재 연결 이름과 IP가 표시되는지 확인합니다.
5. ‘현재 Wi-Fi 기억’을 누릅니다. ‘부팅 시 기억한 Wi-Fi 찾기’도 함께 켜집니다.
   이미 기기에 저장한 Wi-Fi는 ‘저장 목록에서 선택’으로 지정할 수 있습니다.

다음부터
- 완전 부팅 알림을 받으면 최대 60초 동안 Wi-Fi를 켜고 기억한 네트워크에 연결을 시도합니다.
- 요청 간격은 20초입니다. 연결 요청 수락만으로 ‘연결 완료’라고 표시하지 않습니다.
- 다른 Wi-Fi에 이미 연결되어 있으면 부팅 시에는 유지합니다.
  기억한 핫스팟으로 바꾸려면 ‘다시 연결’을 누르세요.
- 휴대폰 핫스팟을 늦게 켜거나, 빠른 재시동/절전 복귀로 완전 부팅 알림이 없으면
  ‘다시 연결’ 버튼으로 시도할 수 있습니다.
- ‘시도 중지’ 또는 설정 화면 열기로 현재 앱의 연결 시도를 끝냅니다.
  기기에 원래 있는 Wi-Fi 자동 연결까지 끄는 기능은 아닙니다.
- ‘기억한 대상 해제’는 앱의 대상과 부팅 연결만 해제합니다.
  저장된 비밀번호를 지우려면 기기의 Wi-Fi 설정을 사용하세요.

기능 범위
- 직접 Wi-Fi 제어는 iQ 3의 Android 5(API 21~22)에 맞춰 구현했습니다.
  다른 Android 버전에서는 설정 바로가기를 사용합니다.
- 앱은 네트워크 이름과 저장 프로필 식별 정보만 보관합니다. 비밀번호를 입력받거나 저장하지 않습니다.
- 제조사 펌웨어나 Wi-Fi 동글이 표준 제어를 지원하지 않으면 실패 안내 후 설정 화면에서 연결합니다.
- Wi-Fi 서비스를 찾았다는 사실만으로 동글이 실제 인식됐다고 판단하지 않습니다.
- 카메라 위에 앱을 띄우지 않습니다. 휴대폰 화면 공유는 매번 휴대폰에서 별도로 승인합니다.

차량을 움직이지 않고 확인할 항목
[ ] Wi-Fi 설정 열기 / 파인 연결 설정 중 하나로 연결 설정 화면이 열린다.
[ ] 핫스팟 연결 후 현재 Wi-Fi 기억이 된다.
[ ] 앱을 닫았다 열어도 기억한 대상과 자동 연결 체크가 남아 있다.
[ ] 핫스팟을 먼저 켜고 내비를 완전 재부팅하면 1분 안에 실제 이름/IP가 표시된다.
[ ] 핫스팟을 끈 채 부팅하면 1분 뒤 시도가 종료된다.
[ ] 나중에 핫스팟을 켜고 ‘다시 연결’을 누르면 연결된다.
[ ] 시도 중지 / 자동 연결 체크 해제 / Wi-Fi 끄기가 적용된다.
[ ] R/D 카메라 전환, 기존 앱 자동 실행, 파인 홈 복귀가 유지된다.
[ ] 미러링은 기존 MIRROR-TEST-0.3-KO.txt 순서로 시험한다.

PC에서 확인한 정책 시험과 실물 성공은 다릅니다. Wi-Fi·동글·제조사 메뉴 진입은 실물 미확인입니다.

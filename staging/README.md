# 최신 설치: Navi 홈 0.6

Wi-Fi 없이 쓰는 iQ 3 홈입니다. **[NaviDiagnostic-0.6.apk](NaviDiagnostic-0.6.apk)**를 기존 앱 위에 업데이트합니다. 앱 이름은 ‘Navi 홈’입니다.

- [SD카드용 묶음](Navi-offline-home-0.6.zip)
- [설치·사용·시험 안내](OFFLINE-HOME-KO.txt)

큰 시계, GPS 속도·수신 정확도, 현재 세션 이동거리·시간, 앱 즐겨찾기와 목록, 밝기·미디어 음량, 제조사 홈 복귀를 제공합니다. 이동 경로는 저장하지 않습니다. 프로세스 종료/재부팅 후 세션 집계는 초기화됩니다.

## 배포 상태

2026-09-17 SD카드의 NaviTest에 0.6 APK와 OFFLINE-HOME-0.6-KO.txt를 복사하고 해시 검증·안전 추출을 마쳤습니다. 사용자 요청으로 이전 홈 APK 0.1~0.4를 삭제했으며 PC 백업은 보존했습니다. 휴대폰용 NaviSender-0.1.apk와 제조사 파일은 유지했습니다. 내비 파일 관리자에서 NaviDiagnostic-0.6.apk를 열어 기존 앱 위에 업데이트해야 합니다.

## 이전 연결 시험

0.5 미러링/Android Auto 묶음과 송신 앱은 보존합니다. 0.6의 설정 → 연결 시험에서도 기존 기능에 들어갈 수 있습니다. 호환 Wi-Fi 동글이나 유선 Android Auto 연결 확보 이후 별도로 시험합니다. OBD는 이번 범위에 없습니다.

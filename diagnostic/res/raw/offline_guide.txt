Navi 홈 0.6 — iQ 3 오프라인 홈

이번 버전은 휴대폰, Wi-Fi 동글, 인터넷 없이 사용합니다.
사용자가 GPS 수신을 확인한 결과를 반영했습니다. 이동거리 정확도와 새 버전의 카메라 공존은 실물 확인이 필요합니다.

설치
1. NaviDiagnostic-0.6.apk를 SD카드의 NaviTest 폴더에 추가합니다.
2. 내비 파일 관리자에서 APK를 열어 기존 앱 위에 업데이트합니다. 기존 앱을 삭제할 필요가 없습니다.
3. 표시 이름은 ‘Navi 홈’입니다. 패키지와 서명을 유지하여 부팅 설정을 이어받습니다.
4. 위치 권한 안내가 나오면 허용합니다. 실행하면 GPS 수신을 시작합니다.

홈
- 시계와 날짜: 기기 시간 기준. 틀리면 파인 설정에서 시간을 확인합니다.
- GPS 속도: 수신한 속도만 km/h로 표시합니다. 신호가 10초 넘게 끊기거나 정확도가 나쁘거나 속도 값이 없으면 — 입니다.
- 이번 이동거리: 현재 세션에서 정상 GPS 좌표 사이의 거리만 더합니다.
- 세션 경과 시간: 앱의 GPS 세션을 시작한 이후 경과 시간입니다. 정차 중이나 GPS 일시 중지 중에도 증가합니다.
- 수신 정확도: GPS가 제공하는 위치 오차 추정치입니다. 수치가 작을수록 좋습니다.
- 즐겨찾기: ‘＋ 앱 추가’로 앱을 지정합니다. 지정된 앱을 누르면 실행합니다.
  변경은 버튼을 길게 누르거나 설정 → 즐겨찾기 편집을 사용합니다.
- 앱 목록: 실행 가능한 설치 앱을 표시합니다. 기존 아틀란을 홈 기능으로 사용하지 않습니다.

설정
- 홈 밝기: 이 홈 화면의 밝기만 20~100%로 조절합니다. 제조사 카메라 밝기는 변경하지 않습니다.
- 미디어 음량: Android 미디어 음량입니다. 제조사 전용 오디오 경로는 별도 확인이 필요합니다.
- GPS 수신: 현재 세션의 GPS 수신을 켜거나 일시 중지합니다.
- 완전 부팅 후 홈 자동 실행: 기존 자동 실행 설정입니다.
- 세션 초기화: 확인 후 이동거리와 경과 시간을 0으로 되돌립니다.
- 기기 상태: Android 버전, 기본 홈, 저장공간, 공개 센서, USB VID/PID를 표시합니다.
  Wi-Fi 기능 선언이 있다는 것만으로 무선 하드웨어가 있다는 뜻은 아닙니다.
- 파인 홈 / 파인 설정 / 기본 홈 설정 / 자동 실행 해제: 제조사 화면 복귀와 복구용입니다.
- Wi-Fi 관리 / 연결 시험: 이전 미러링·Android Auto 시험 기능입니다. 이번 오프라인 시험에서는 건너뛰어도 됩니다.
- 상세 GPS 진단은 해당 화면만의 진단입니다. 홈 GPS 세션의 중지는 홈 설정에서 합니다.
- 세션 종료: GPS 수신을 끝내고 현재 집계를 지웁니다. 다시 홈을 열면 새 세션입니다.

데이터 범위
- 좌표와 이동 경로는 저장하거나 전송하지 않습니다. 메모리에는 거리 계산용 직전 좌표만 유지합니다.
- 이동거리와 경과 시간은 현재 프로세스 메모리에만 있습니다. 앱 종료, 시스템의 프로세스 종료, 재부팅 후 복원하지 않습니다.
- 카메라나 다른 앱으로 전환해도 GPS 서비스가 살아 있는 동안 현재 집계를 이어갑니다.
- 앱이 카메라 위로 올라오도록 강제 실행하거나 오버레이를 사용하지 않습니다.
- GPS 정확도 30m 초과, 수신 간격 5초 초과, 비정상 좌표 이동은 거리에서 제외합니다.
- 정차 흔들림을 줄이기 위해 양쪽 좌표의 제공 속도가 1.5m/s(약 5.4km/h) 이상일 때만 거리를 더합니다.
  따라서 서행·주차 구간은 덜 집계될 수 있습니다. 차량 계기판 누적 거리계나 정밀 측량을 대체하지 않습니다.
- 미수신 구간의 거리는 추정해 채우지 않습니다.

정차 상태에서 10~15분 확인
1. 업데이트 후 차콜·청록색 홈이 보이고 버튼이 잘 눌리는지 확인합니다.
2. GPS 수신 시 속도·정확도가 표시되는지 확인합니다. 정차했을 때 속도가 0 근처인지 봅니다.
3. 3분간 정차한 상태에서 이동거리가 계속 늘지 않는지 봅니다.
4. 즐겨찾기 한 개 지정 → 실행 → 우리 홈 복귀를 확인합니다.
5. 브레이크를 유지하면서 R/D 카메라 전환을 각각 3회 확인합니다.
   카메라가 가려지지 않는지, 기기가 우리 홈으로 돌려보냈을 때 세션 시간이 이어지는지 봅니다.
6. 설정에서 GPS를 일시 중지하면 속도가 — 로 바뀌는지 확인합니다. 다시 켜서 수신을 확인합니다.
7. 밝기·음량을 조절해 반응을 확인합니다.
8. 완전 재부팅 후 홈 자동 실행, 즐겨찾기·밝기 유지, 세션 거리·시간 초기화를 확인합니다.
9. 파인 홈 복귀를 확인합니다.
별도 주행 없이 위 시험을 할 수 있습니다. 실제 주행 거리 정확도는 나중에 확인합니다.

알려주실 결과
- 설치 성공 여부 / GPS 속도와 정확도 표시
- 정차 중 거리 증가 여부
- R/D 카메라 표시와 홈 복귀
- 자동 실행 / 즐겨찾기 / 밝기·음량
- 실패 화면과 오류 문구

Wi-Fi 조사
iQ 3 공식 설명서 21쪽은 ‘리얼타임3D 전용 WiFi 동글’을 별매품으로 안내합니다.
42쪽은 휴대폰 핫스팟 비밀번호를 입력하는 수동 연결을 설명합니다.
현재 기기에서 사용하려면 호환 동글 장착·인식부터 확인해야 합니다. 일반 PC용 USB 무선랜이나 최신 파인뷰 블랙박스 동글의 호환성은 확인되지 않았습니다.
